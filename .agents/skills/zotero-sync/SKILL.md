# Zotero Citation Sync

## Context
As defined in `conventions.md` (Convention 7), Zotero is the absolute master source for all citations. We use Better BibTeX to automatically export to `references.bib`. To prevent hallucinations and track exactly what is added or removed from our reading list, we maintain a snapshot (`references_backup.bib`) and run a diff script before committing changes.

## Trigger
Run this skill whenever the user indicates they have added, removed, or modified papers in Zotero, or whenever a new citation is needed that requires pulling from Zotero.

## Workflow Steps

### 1. Verify Auto-Export
Confirm with the user that Zotero has successfully auto-exported the latest collection to `references.bib` (via the Better BibTeX plugin).

### 2. Run the Comparison Script
Run the Python script located in the project management directory to diff the keys between the old backup and the new export.

```powershell
python "c:\Users\Deuts\OneDrive - Delft University of Technology\Misc\Gemini\Aa Project management\Academics\BEP\Catalysis\0_Project_Management\check_zotero_sync.py"
```

### 3. Review Changes with User
Analyze the output of the script:
- **[+] ADDED:** List the new citekeys. Verify if these are the papers the user intended to add.
- **[-] REMOVED:** List the removed citekeys. Check the LaTeX files to ensure none of the removed keys are currently being `\cite{...}`ed. If they are, warn the user that the compilation will fail.

### 4. Update the Backup Snapshot
Once the changes are confirmed, update the backup snapshot so it represents the new baseline for the next sync. Do NOT use `cp` or `copy` in bash, use powershell's `Copy-Item` or python to overwrite `references_backup.bib` with the contents of `references.bib`.

### 5. Update Project State (Optional)
If a new paper was added that acts as a core reference, update `resources.md` and/or `literature_index.md` to track it, and assign a subagent (e.g. `bep-paper-analyzer`) to extract quotes and perform a literature analysis on the new PDF.

## Critical Rules
* **Never edit `references.bib` manually.** It is generated by Zotero. Any manual edits will be overwritten on the next sync.
* **Never hallucinate citekeys.** If a citekey does not appear in the `[+] ADDED` list or the existing `references.bib`, it does not exist.
