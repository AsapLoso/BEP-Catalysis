# BEP-Catalysis

Research, modeling, and thesis work for the TU Delft Bachelor End Project on acetylene semi-hydrogenation in packed-bed reactors.

## Start here

- [Notebook layout](./notebooks/README.md): personal working notebook, reference implementations, and benchmarks.
- [Research layout](./research/README.md): literature, model specifications, audits, meeting notes, prompts, and planning maps.
- [Structure.md](./Structure.md): project modeling framework and conventions.

The personal working notebook is [notebooks/unified_dynamic_reactor.ipynb](./notebooks/unified_dynamic_reactor.ipynb). Other notebooks are reference material or benchmark records; their individual status is documented in the notebook indexes.
