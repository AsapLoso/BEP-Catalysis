## Technical note — why not delete the existing YAML?

Deleting the existing dataset would alter the working reference system, confuse historical node IDs and produce avoidable merge/revert churn. It also would not erase the old map from Git history or source summaries. A **new path and blind-stage input whitelist** preserve both recoverability and the later comparison, though perfect scientific independence still cannot be guaranteed in the same repo.
