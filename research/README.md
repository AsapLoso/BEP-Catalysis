# Research files

This folder groups the evidence and planning behind the reactor notebooks. Use this index to tell source material, analysis, and planning apart.

## Source material

- [literature/](./literature/) contains papers, extracted text, and literature indexes. Verify scientific claims against the primary source files.
- [specs/v3/](./specs/v3/) contains the V3 scope, source manifest, model blueprint, theory crosswalk, audit trail, and handoff drafts. The V3 implementation itself lives under [notebooks/reference/v3/](../notebooks/reference/v3/).
- [audits/](./audits/) contains focused model reviews and any calculations supporting those reviews.

## Project context and planning

- [notes/meetings/](./notes/meetings/) contains meeting records and project context.
- [wayfinder/](./wayfinder/) contains decision maps and their associated planning prompts. These are plans and open questions, not implemented model code or approval of scientific-map changes.
- [prompts/](./prompts/) contains cross-cutting prompts that do not belong to one Wayfinder map.

Notebook locations and their roles are indexed in [../notebooks/README.md](../notebooks/README.md). Keep personal scientific mind maps separate from these planning maps and follow the map-review instructions before changing one.
