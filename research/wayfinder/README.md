# Wayfinder plans

This folder holds project decision maps and their dispatch prompts. These documents track destinations, open work, and proposed deliverables; they are not implementation directories or scientific mind maps.

- [bep_v4_reactor_model.md](./bep_v4_reactor_model.md) is the current reactor planning map. Its V4 notebook deliverable is planned for [notebooks/reference/v4/](../../notebooks/reference/v4/README.md); that implementation is not present yet.
- [bep_v3_reactor_model.md](./bep_v3_reactor_model.md) is a short pointer retained for the prior V3 planning thread.
- [prompts/](./prompts/) contains the dispatch prompts associated with these plans.

Keep planning maps here. Personal scientific map changes follow the separate map-review procedure.
